# Vacancy Analyzer
Проект для анализа вакансий с платформы HeadHunter (hh.ru). 

Позволяет искать, фильтровать, сравнивать и сохранять вакансии в удобном формате.

## 📌 Возможности
🔍 Поиск вакансий по ключевому слову на hh.ru  
📂 Сохранение результатов в JSON-файл и базу данных PostgreSQL  
🗂 Фильтрация вакансий по ключевым словам  
📊 Сравнение вакансий по уровню зарплаты  
🧹 Очистка сохраненных данных  
📝 Читаемое представление вакансий  
📊 Расширенная аналитика через базу данных  

## 🆕 Новый функционал
### Работа с базой данных PostgreSQL:
✅ Сохранение вакансий в реляционную базу данных  
✅ Получение статистики по компаниям и вакансиям  
✅ Поиск вакансий с зарплатой выше средней  
✅ Анализ средней зарплаты по вакансиям  
✅ Полнотекстовый поиск по описанию вакансий  

### Улучшенный анализ:
📈 Сравнение зарплатных предложений по компаниям  
🔎 Фильтрация по диапазону зарплат  
🏆 ТОП компаний по количеству вакансий  

## ⚙️ Установка
### Требования:
- Python 3.8+
- PostgreSQL 12+
- Учетные данные для подключения к БД

### Клонируйте репозиторий:
```bash
git clone https://github.com/Kysnez4/kurs2.git
cd vacancy_analyzer
### Установите зависимости:

### Настройка базы данных:

Создайте базу данных в PostgreSQL:
```sql
CREATE DATABASE vacancy_analyzer WITH ENCODING 'UTF8';
```
#  Использование
Запустите программу:

```bash

```
### После запуска следуйте инструкциям в консоли:

1. Основной рабочий процесс:

2. Введите данные для подключения к PostgreSQL
